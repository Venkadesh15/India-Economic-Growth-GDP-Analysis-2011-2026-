# 🇮🇳 India’s Economic Growth & GDP Analysis (2011–2026)

An interactive **Power BI dashboard** analyzing India’s GDP, state-wise GSDP, GDP growth, quarterly trends, and sector-wise GVA.

## 🎯 Objective

* Analyze India’s GDP growth over time
* Compare state-wise GSDP
* Identify high-performing states
* Analyze GDP growth trends
* Understand sector-wise GVA contribution
* Present economic data through interactive visualizations

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Data Modeling
* Microsoft Excel
* Data Visualization

## 📊 Dashboard

The dashboard includes:

* Total GSDP
* GDP Growth Rate
* Highest GSDP State
* Latest GDP
* India GDP Trend
* Top States by GSDP
* Sector-wise GVA Contribution
* Quarterly GDP Growth
* State-wise GSDP Analysis

## 🎛️ Interactive Slicers

* Financial Year
* State
* Price Type
* Sector

## 🧹 Data Preparation

Data was cleaned and transformed using **Power Query**, including data type correction, financial-year standardization, column preparation, and dataset transformation.

## 🧩 Data Modeling

The project uses a structured Power BI data model with fact and dimension tables to support efficient analysis and interactive filtering.

## 💡 Key Learning

This project strengthened practical skills in:

**Data Cleaning → Data Transformation → Data Modeling → DAX → Visualization → Data Storytelling**
